# Introduction to AI, ML and Deep Learning

## 1. What is Artificial Intelligence?

Artificial Intelligence (AI) is a branch of computer science that focuses on creating machines and software that can perform tasks that normally require human intelligence.

Examples:
- Voice assistants
- Chatbots
- Recommendation systems
- Image recognition
- Self-driving technology

## 2. What is Machine Learning?

Machine Learning (ML) is a subset of Artificial Intelligence. It allows computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every situation.

Examples:
- Spam email detection
- Movie recommendations
- Fraud detection
- House price prediction

## 3. What is Deep Learning?

Deep Learning is a subset of Machine Learning that uses artificial neural networks with multiple layers to learn complex patterns from large amounts of data.

Examples:
- Face recognition
- Speech recognition
- Image classification
- Natural language processing

## 4. Difference Between AI, ML and Deep Learning

| AI | ML | Deep Learning |
|---|---|---|
| Broad field of intelligent machines | Subset of AI | Subset of ML |
| Can use different techniques | Learns from data | Uses neural networks |
| Includes ML and other methods | Uses algorithms to find patterns | Usually needs more data and computing power |

## 5. Real-World Applications of AI

### Healthcare
AI can help analyze medical images and support diagnosis.

### Education
AI can provide personalized learning and automated feedback.

### Banking
AI and ML can be used for fraud detection and risk analysis.

### Transportation
AI is used in navigation, traffic prediction and driver-assistance systems.

### Entertainment
Recommendation systems suggest movies, music and other content based on user activity.

## 6. Python

Python is a high-level, interpreted programming language. It is widely used in AI, Machine Learning, Data Science and software development because of its simple syntax and large collection of libraries.

## 7. Python Concepts Learned

- Variables
- Data types
- Input and output
- Conditional statements
- For loops
- While loops
- Lists
- Functions

## 8. Conclusion

AI is the broader concept of creating intelligent systems. Machine Learning enables systems to learn from data, while Deep Learning uses neural networks to learn complex patterns. Python is one of the popular programming languages used for AI and Machine Learning.
